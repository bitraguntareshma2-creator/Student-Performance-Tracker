
# Student Performance Tracker

## Project Name
Student Performance Tracker

## Project Description
This project uses Python to calculate student marks,
percentages, grades, and pass/fail status.

It also generates a bar chart to compare student marks
and saves the student report as a CSV file.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Google Colab

## Features
1. Calculate total marks and percentage.
2. Assign grades to students.
3. Display student results.
4. Generate a bar chart.
5. Export student reports to CSV.
